# Data

This repo expects `ObesityDataSet.csv` in this folder. The file is a third-party public dataset and is not redistributed here.

Download it from UCI "Estimation of obesity levels based on eating habits and physical condition" (dataset #544): https://archive.ics.uci.edu/dataset/544

and save it as `data/ObesityDataSet.csv`, then run the script from the repository root.
